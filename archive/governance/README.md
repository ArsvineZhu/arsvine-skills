# Historical Governance

This directory preserves governance documents that preceded AntiGPT.

```text
JDD → TED → COST → AntiGPT
```

- **JDD** focused on justified machinery and resistance to speculative engineering.
- **TED** reframed engineering burden through total Token cost.
- **COST** generalized the model to expected total cost across the software trajectory.
- **AntiGPT** moved the governing model to Agent behavior itself: judgment, objective preservation, ownership-level correction, bounded investigation, bounded verification, and resistance to defensive cognition.

These files are historical sources. They do not define current repository or Agent policy. Current governance is `../../AntiGPT/CONSTITUTION.md` plus the AntiGPT role Skills.

The archived documents are intentionally preserved close to their original form. Historical wording may conflict with current AntiGPT doctrine.
