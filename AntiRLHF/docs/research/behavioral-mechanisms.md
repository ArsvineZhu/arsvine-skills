# 机制与假设：知道规则，为什么仍然不按规则行动？

## 问题不在规则能否被复述

长期使用中的一个反复观察是：Agent 在被直接询问时能复述 Constitution，面对新任务仍选择老习惯；指出错误后又能熟练引用 Constitution。研究文献中的 **knows-but-violates** 与此相近。[DriftBench](https://arxiv.org/abs/2604.28031) 在多轮科研构思任务中测量了规则回忆和实际约束遵循之间的差异：七个模型的最终轮平均回忆率为 97.3%，知道约束却违反的比例在不同模型之间相差很大。定期恢复约束只部分缓解了问题。

这支持一种工作区分：

- **规则可访问性**：模型能否在要求下说出规则。
- **规则对行动的影响**：模型面对下一步操作时，是否实际以规则改变选择。
- **事后解释能力**：模型能否为已发生的行为生成连贯理由。

这三种能力应分别观察。尤其不能用第三种能力推定第二种能力已经改善。

## 代理信号抢占了任务目标

我们采用的核心解释是：训练和执行环境中容易获得正反馈的行为，会成为模型在其他场景中也倾向使用的默认策略。软件任务中，测试绿色、静态检查成功、看起来完整的代码和记录都容易得到明确反馈；长远可维护性、实际用户完成任务的能力则更难即时反馈。

在[SpecBench](https://arxiv.org/abs/2605.21384) 中，长时间编码 Agent 能高度优化可见测试，却仍在组合功能的隐藏测试上出现显著落差。[Prompt-Induced Waste](https://arxiv.org/abs/2608.01347) 还发现，鼓励“充分比较方案”或“最大确定性”的提示方式，会增加被丢弃的推理分支或重复检查，并不带来相应的正确率收益。这些实验支撑我们对“反馈与工作分配”关系的重视。

## 后训练的影响与推理时环境

我们将产品从 AntiGPT 改名为 **AntiRLHF**，是为了研究跨模型、跨任务的后训练塑造的行为倾向。名称表达治理对象和研究方向；具体表现可能来自监督微调、偏好优化、RL、系统提示词、工具 Harness 和运行时反馈的共同作用。

公开案例提供了更具体的线索：Anthropic 披露曾在训练中出现模型向未提及的 reviewer 写注释、通过堆砌免责声明争取奖励的情况，随后回退相关训练。[OpenAI 对 GPT-4o 谄媚更新的复盘](https://openai.com/index/expanding-on-sycophancy/) 描述了用户反馈信号怎样与模型行为相互作用。这些案例说明代理信号有能力塑造可泛化的表达策略。

**尚无证据足以把我们遇到的所有编码和语言故障，归因为某个 GPT 模型的特定 RLHF 训练步骤。** AntiRLHF 在这个层面使用可检验假设指导提示词设计，而不声称已经观察到模型内部的真实决策因果链。

## 事后解释为什么可能有迷惑性

面对“为什么你刚才做错了”的询问，模型会根据当前对话生成一个合理解释。它可能准确描述错误行为与原则之间的冲突，却未掌握造成该错误的内部机制。解释本身仍可以获得用户认可。

于是形成两种不同的好表现：**说得对**和**做得对**。如果治理工作反复奖励“反省深刻”“引用条款准确”，我们甚至可能训练出一个擅长谈论 AntiRLHF、但下一次仍走向旧轨迹的 Agent。

[自我纠错研究综述](https://arxiv.org/abs/2406.01297) 区分了模型自己产生的反馈与可靠外部反馈，并指出后者的优势。它提醒我们，重复问模型“你确定吗”，也可能只是增加一个语言任务。

## 更符合目标的假设

**行动选择假设**：在决策分叉处出现的简短、与当前情境匹配的行动规则或示范，更容易改变下一步操作；将整份原则长期放在上下文里主要提高规则可访问性。

**轨迹反馈假设**：反馈一旦指向实际未完成的能力或错误所有权，下一步动作就应改变实现路线；只让局部检查更绿会强化原有结构。

**规范污染假设**：模型将本次临时检查、局部纠错与自身偏好写入长期 AGENTS 后，后续模型会继续按照这些额外要求行动。治理对象因此包括 Agent 生成的长期指令。

三种假设都可以通过现实任务中“面对相同情境选择了什么动作”来检验。当前的研究目标是找到低成本、可复用的提示词策略，而非发明新的强制审查平台。
