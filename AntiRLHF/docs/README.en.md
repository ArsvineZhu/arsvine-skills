# AntiRLHF Research Notes

[中文](README.md)

This is a working research archive maintained alongside the AntiRLHF governance bundle. It records observed failures, mechanism hypotheses, inference-time prompt interventions, and the sources that motivated them. The Chinese essays are the authoritative editions; this page provides an English entry point.

The central question is **whether a stated principle changes an agent's next action**. Models may recall rules and explain violations convincingly while continuing to select actions that optimize easy-to-demonstrate local results.

## Reading

- [Field observations](research/field-observations.md) — repeated failures in coding, writing, and correction (Chinese).
- [Behavioral mechanisms](research/behavioral-mechanisms.md) — what is observed, inferred, and still open (Chinese).
- [Prompt strategy](research/prompt-strategy.md) — choices for persistent instructions, role Skills, and action examples (Chinese).
- [Literature and community notes](research/literature-and-community.md) — English bibliography and bounded interpretation.

This archive is research material, not an extra operational policy. The active [Constitution](../CONSTITUTION.md) and [Skills](../INDEX.md) define agent behavior.
